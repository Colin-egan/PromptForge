## Desk Organizers

### Example 1: Three-Compartment Organizer (RECOMMENDED FOR MAIN DEMO)

**Prompt:**
```
I need a desk organizer with three compartments: one for pens (30mm diameter), 
one for sticky notes (80mm x 80mm), and one for paperclips (40mm x 60mm). 
Make it 120mm wide total with 2mm walls and rounded corners.
```

**Expected Features:**
- Three distinct compartments with specified dimensions
- 2mm wall thickness
- Rounded corners (fillets)
- Approximately 120mm total width
- Flat base for desk placement

**Demo Talking Points:**
- "Notice how it understood three different compartment types"
- "The dimensions are precise — 30mm for pen diameter"
- "Rounded corners make it print-friendly and aesthetically pleasing"

**Follow-up Edits:**
1. "Make the pen compartment 20% deeper"
2. "Add a slot on the left side for charging cables, 15mm wide"
3. "Round the bottom edges more, with a 5mm fillet"

**Parameters to Demonstrate:**
- `pen_diameter`: 25-40mm
- `wall_thickness`: 1.5-4mm
- `height`: 40-100mm
- `corner_radius`: 2-8mm

## Prompt Engineering Tips

### What Works Well
- ✅ Specific dimensions (mm)
- ✅ Functional requirements (drainage, mounting)
- ✅ Material considerations (wall thickness)
- ✅ Real-world use cases (desk, wall-mounted)
- ✅ Geometric descriptions (hexagonal, rounded)

### What to Avoid
- ❌ Vague requests ("something nice")
- ❌ Organic shapes ("realistic face")
- ❌ Moving parts (gears, hinges) - not yet supported
- ❌ Extremely complex assemblies
- ❌ Unrealistic dimensions (too large/small)

### Editing Best Practices
- ✅ Specific modifications ("make X wider")
- ✅ Incremental changes (one thing at a time)
- ✅ Dimensional adjustments ("increase by 20%")
- ✅ Feature additions ("add a slot")
- ❌ Complete redesigns ("make it totally different")

## Success Metrics

### Generation Success
- ✅ Model generates in < 15 seconds
- ✅ Geometry is manifold (watertight)
- ✅ Dimensions match request
- ✅ Features are present and functional

### Edit Success
- ✅ Edit applies in < 10 seconds
- ✅ Original structure preserved
- ✅ Only requested change made
- ✅ No unintended side effects

### Print Success
- ✅ STL exports without errors
- ✅ Slicer accepts file
- ✅ No mesh repair needed
- ✅ Prints successfully on first attempt

## Troubleshooting

### If Generation Fails
1. Check prompt clarity
2. Verify dimensions are reasonable
3. Try simpler version first
4. Check self-correction attempts in logs

### If Edit Doesn't Apply
1. Be more specific about what to change
2. Reference existing features by name
3. Try smaller incremental changes
4. Check if request is ambiguous

### If Model Isn't Printable
1. Check wall thickness (min 1.5mm for PLA)
2. Look for overhangs > 45°
3. Verify no trapped volumes
4. Check if supports are needed
