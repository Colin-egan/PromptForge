### 4.4 Self-Correction Loop
**Goal:** Automatically fix CadQuery execution errors

**Actions:**
- Create `backend/app/agents/corrector.py`
- Implement correction pipeline:
  1. Execute generated code in sandbox
  2. If error occurs, capture full traceback
  3. Feed error back to Granite with original prompt
  4. Request corrected code
  5. Retry execution (max 3 attempts)
  6. If still failing, surface error to user with explanation
- Parse common CadQuery errors:
  - Boolean operation failures
  - Invalid geometry (self-intersecting)
  - Missing imports
  - Syntax errors
  - Dimension conflicts
- Provide error context to LLM:
  - Error type and message
  - Line number where error occurred
  - Relevant code snippet
  - Suggested fix direction

**Error Handling Strategy:**
```
Attempt 1: Generate code
  → Error: "Boolean operation failed"
  
Attempt 2: Regenerate with error context
  → Error: "Still failing"
  
Attempt 3: Regenerate with simplified approach
  → Success or surface to user
```

**Deliverables:**
- `backend/app/agents/corrector.py`
- Error parsing utilities
- Retry logic with exponential backoff

## Phase 5: Print-Readiness Analysis

### 5.1 Geometric Analysis Engine
**Goal:** Detect printability issues in generated models

**Actions:**
- Create `backend/app/agents/analyzer.py`
- Implement geometric checks:
  
  **Wall Thickness Analysis:**
  - Sample mesh at multiple points
  - Use ray casting to measure wall thickness
  - Flag walls < 0.8mm (too thin for FDM)
  - Flag walls < 0.4mm (too thin for resin)
  
  **Overhang Detection:**
  - Calculate face normals from mesh
  - Identify faces with Z-component < cos(45°)
  - Flag overhangs requiring supports
  - Suggest optimal print orientation
  
  **Trapped Volume Detection:**
  - Analyze mesh topology
  - Identify enclosed cavities with no drainage
  - Flag potential resin traps or support removal issues
  
  **Manifold Validation:**
  - Check for non-manifold edges
  - Verify watertight geometry
  - Detect self-intersections
  
  **Dimensional Checks:**
  - Verify bounding box fits common print beds
  - Check for extremely small features (< 0.5mm)
  - Validate aspect ratios for stability

**Technical Implementation:**
- Use trimesh library for mesh analysis
- Implement custom algorithms for wall thickness sampling
- Use numpy for vector math and normal calculations

**Deliverables:**
- `backend/app/agents/analyzer.py`
- Geometric analysis utilities
- Test suite with known-good and known-bad models

## Risk Mitigation

### Technical Risks
1. **CadQuery Complexity:**
   - Risk: Generated code produces invalid geometry
   - Mitigation: Extensive few-shot examples, self-correction loop, validation

2. **LLM Hallucination:**
   - Risk: Granite generates non-functional code
   - Mitigation: RAG with real documentation, syntax validation, execution testing

3. **Performance:**
   - Risk: Model generation takes too long
   - Mitigation: Optimize sandbox, cache common patterns, async processing

4. **Sandbox Security:**
   - Risk: Malicious code execution
   - Mitigation: Docker isolation, resource limits, no network access

### Project Risks
1. **Scope Creep:**
   - Risk: Adding too many features
   - Mitigation: Stick to MVP, prioritize core workflow

2. **Integration Complexity:**
   - Risk: Components don't work together
   - Mitigation: Early integration testing, clear interfaces

3. **Time Constraints:**
   - Risk: Not finishing by deadline
   - Mitigation: Phased approach, MVP first, polish later
